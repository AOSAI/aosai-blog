CNN：卷积神经网络

约 3955 字大约 13 分钟

神经网络CNN

1. 历史动机：MLP 在图像任务上的困境

1.1 一张图的代价

上一篇文章里，我们用 MLP 解决了 XOR 分类问题。那 MLP 能不能处理图像？

假设一张 224×224 的 RGB 图片。MLP 的第一步一定是展平（flatten）—— 把二维像素拍成一维向量：224×224×3 = 150,576 个输入。

第一个隐藏层如果只设 1000 个神经元，权重 WWW 的形状就是 1000 × 150576——光是这一层就有 1.5 亿个参数。如果用 FP32 存（每个参数 4 字节），这一层就要 600 MB。一张 A100 80G，第一层就吃掉将近 1%。

左半边展示的就是这个问题：一个 4×4 的小图（16 个像素）全连到 32 个隐藏神经元，就已经 512 个参数了。换成真实尺寸（224×224×3），参数量直接翻几十万倍。

1.2 局部性：一个过于明显的先验知识

你现在看着这篇文章的页面，你的眼睛并不是一次性"看清"整页的内容。你的目光会聚焦在某个词、某一行——你天生就知道：相邻的文字之间关系更紧密，左上角和右下角的文字没什么关系。

图像也是同样的道理。一张猫片里，决定"这是猫耳朵"的信息，全都在耳朵附近那几个像素里。远处的像素对"这里是不是耳朵"基本没有贡献。

这就是局部性先验（Local Prior）：邻近像素之间关系紧密，远处的像素之间关系微弱。

MLP 的全连接结构完全无视了这个先验——它把每个像素和每个神经元都连了一遍，对远处的像素和近处的像素一视同仁。这就像给每个人发一份全公司的通讯录，但他真正需要的只是小组里几个人的联系方式。

1.3 1989：第一个实例——LeNet

1989 年，Yann LeCun 在贝尔实验室发表了一篇论文，提出了 卷积神经网络（CNN）——一个专门为图像设计的新结构家族。它在 MLP 的基础上只改了两件事：

  1. 局部连接（Local Connectivity）：每个神经元只看输入的一小片区域
  2. 权值共享（Weight Sharing）：同一个检测器扫遍整张图

这两件事一起，把图像处理的参数量从 O(n2)O(n^2)O(n2) 降到了 O(k2)O(k^2)O(k2)（kkk 是卷积核大小，通常 3 或 5）。LeCun 用这个结构搭出了 LeNet——CNN 家族的第一个成功实例，用在了手写数字识别（支票识别）上。

一句话记住：CNN 的两个结构创新，本质上是把"无差别全连接"改成了"局部连接 + 权值共享"。

LeNet 只是一个开始。后面还有 AlexNet、VGG、ResNet……每个都在它的结构上做了改进，这些会在各自的文章中单独介绍。

2. 卷积层的结构拆解

2.1 局部连接：每个神经元只看一小片

在 MLP 里，每个隐藏神经元连到前一层所有神经元。在 CNN 里，每个神经元只连到前一层的一个局部窗口（感受野）。

回头再看 Fig.1 的右半边就能很直观地理解：输入特征图上框出一个 3×3 的区域，只从这个区域取信息，算出一个输出值。其他位置的信息完全不参与这个输出值的计算。

局部连接的效果一目了然：

  • MLP：一个输出依赖全图 → 参数量随输入尺寸平方增长
  • CNN：一个输出只依赖局部窗口 → 参数量只受卷积核大小控制

2.2 权值共享：一个橡皮章盖满整页纸

局部连接只解决了一半问题。如果每个局部窗口都用不同的权重，大图的参数量还是很大。

权值共享的思路更极端：所有局部窗口共用同一组权重。

卷积核（3×3 的权重矩阵）在输入特征图上滑动。位置 1 用这组权重算出一个输出，滑到位置 2 还是用同一组权重。整张图只学 k×kk \times kk×k 个权重，而不是每个位置学一套。

2.3 一张表看懂所有结构参数

在讲参数之前，先搞清楚一件事：一张图有几个维度？

你可能已经习惯了"图片是 224×224"，但 RGB 彩图不是。位置 (0,0) 处不是一个数字，而是三个（R=255, G=100, B=80）。整张图是一张 H×W 的网格，网格的每个格子里放了 C 个数字——这就是形状 (H, W, C) 的含义，C 叫通道数，也叫厚度。

卷积层要同时改变 H、W、C 三个维度。下面这 4 个结构参数就是用来控制这件事的：

参数符号含义直觉
卷积核大小kkk每次看多大范围3×3 看邻居，7×7 看大片区域
步长sss窗口每次移多远s=1 密扫，s=2 跳着看
填充ppp边缘要不要补补了大小不变，不补越卷越小
输出通道数coutc_{out}cout​用几种卷积核每个通道学一种特征

输出特征图的高宽计算公式：

Hout=⌊Hin+2p−ks⌋+1H_{out} = \left\lfloor\frac{H_{in} + 2p - k}{s}\right\rfloor + 1 Hout​=⌊sHin​+2p−k​⌋+1

C_out 去哪了？——它不在这个公式里。空间尺寸（H, W）只由 k, s, p 控制，C_out 直接由你想用多少个卷积核决定，这两个维度互不干扰。完整的形状变化是：

(Cin,Hin,Win)→卷积(Cout,Hout,Wout)(C_{in}, H_{in}, W_{in}) \xrightarrow{\text{卷积}} (C_{out}, H_{out}, W_{out}) (Cin​,Hin​,Win​)卷积​(Cout​,Hout​,Wout​)

拿一个具体的例子串一遍：输入 224×224×3（C_in=3），k=3, s=1, p=1：

  • Hout=⌊(224+2−3)/1⌋+1=224H_{out} = \lfloor (224 + 2 - 3) / 1 \rfloor + 1 = 224Hout​=⌊(224+2−3)/1⌋+1=224，W 同理
  • C_out 设为 16
  • 输出形状：16×224×224（厚度从 3 变 16，空间尺寸不变）

2.4 输入通道 → 输出通道的转换

上一节都在说单通道的情形。但实际中，卷积层的输入和输出都是多通道的：

  • 输入图像：3 通道（RGB）
  • Conv1 输出：16 通道（16 种不同的特征）
  • Conv2 输出：32 通道

多通道卷积是怎么做的？想象你有 cinc_{in}cin​ 张输入特征图叠在一起。每个输出通道对应 cinc_{in}cin​ 个不同的卷积核（每张输入图配一个核）。这 cinc_{in}cin​ 个核各自在对应的输入图上滑动，计算结果相加，再加偏置，得到该输出通道的一个像素。

一个输出通道=∑i=1cin(核i∗输入通道i)+b\text{一个输出通道} = \sum_{i=1}^{c_{in}} (\text{核}_i * \text{输入通道}_i) + b 一个输出通道=i=1∑cin​​(核i​∗输入通道i​)+b

参数量也随之变化：

配置参数量示例
单输入→单输出k2k^2k23×3 → 9
cinc_{in}cin​→单输出cin⋅k2c_{in} \cdot k^2cin​⋅k23→3×3 → 27
cinc_{in}cin​→coutc_{out}cout​cout⋅cin⋅k2c_{out} \cdot c_{in} \cdot k^2cout​⋅cin​⋅k216→32, 3×3 → 4608

你可能注意到一件事：上面全在说"卷积层"，没说"卷积神经网络"。卷积层 ≠ CNN。卷积层只是一块积木——一个特征提取器。把多个卷积层堆叠起来，中间插池化层，最后接全连接分类头，才是完整的 CNN。第 3 节展示的就是这个"搭积木"的过程。

3. 信息流动：从卷积到分类

3.1 LeNet-5：来自论文的真实结构

前面都在说卷积层的设计原理。现在看一个真实的 CNN 结构——1998 年 LeCun 在论文中提出的 LeNet-5，它就是 CNN 家族的第一个实践验证。LeNet-5 的完整数据流如下：

输入 32×32 (灰度)
→ C1: 6 个 5×5 卷积, stride=1     → 28×28×6
→ S2: 2×2 AvgPool, stride=2        → 14×14×6
→ C3: 16 个 5×5 卷积, stride=1     → 10×10×16
→ S4: 2×2 AvgPool, stride=2        → 5×5×16
→ C5: 120 个 5×5 卷积              → 1×1×120
→ F6: 全连接 120→84                 → 84
→ 输出: 全连接 84→10               → 10

注意看 C1、C3、C5 这三层，每层卷积完 H, W 都在缩小——C1 从 32 到 28，C3 从 14 到 10，C5 从 5 到 1。这是因为 LeNet-5 的卷积层没有 padding（p=0p=0p=0），一个 5×5 的核扫过 32×32 的图，能走到的中心位置只有 28×28 个。所以输出比输入小了 4，公式就是 Hout=Hin−k+1H_{out} = H_{in} - k + 1Hout​=Hin​−k+1。

这对现在习惯用 padding=1 保持尺寸的人来说可能有点反直觉。「不补边的卷积层自己就在做下采样」——LeNet-5 时代没有特意把"下采样"这件事全交给池化层，卷积层也在分担这个任务。直到 VGG（2014）才统一成"卷积层只负责提取特征（保持尺寸），池化层负责下采样（缩小尺寸）"。

用 Fig.3 和一张更详细的表来看每一步发生了什么：

层操作输入形状输出形状可学参数量备注
输入—1×32×32—0灰度图，单通道
C1Conv 5×5, 6 filters1×32×326×28×28(5×5×1+1)×6 = 156边缘检测层，28=32-5+1
S2AvgPool 2×2, stride 26×28×286×14×140池化无参数，空间缩小一半
C3Conv 5×5, 16 filters6×14×1416×10×10(5×5×6+1)×16 = 2416组合低层特征，10=14-5+1
S4AvgPool 2×2, stride 216×10×1016×5×50再次下采样
C5Conv 5×5, 120 filters16×5×5120×1×1(5×5×16+1)×120 = 481205×5 核在 5×5 输入上卷出 1×1
F6FC 120→8412084120×84+84 = 10164全连接层，学分类决策
输出FC 84→10841084×10+10 = 85010 类数字输出

整个 LeNet-5 的可学参数加起来只有 ~62K（算下来 61706），和前面 1.5 亿的 MLP 天壤之别。

一个小补充：CNN 里的卷积核 ≈ MLP 里的"神经元"。区别在于 MLP 的每个神经元只看一个数字（标量），CNN 的每个卷积核扫遍全图，输出一张特征图——相当于一个"全图扫描版"的神经元。C1 层的 6 个卷积核 = 6 个神经元，C3 层的 16 个 = 16 个。

这里有几个细节和原始论文的区别，知道了不坏事：

  • 原始论文的 C3 层用了稀疏连接表（不是每个输入通道连所有输出通道），这里的计算假设是全连接，参数量略有差异，但不影响结构理解
  • 原始论文的 S2 和 S4 是带可学参数的可训练池化层，这里简化为无参数的 AvgPool，核心的空间下采样效果相同
  • 原始论文的输出层用的是 RBF（径向基函数），这里简化为全连接，分类目标不变

3.2 代码视角：只搭结构，不训练

PyTorch 里定义一个 LeNet-5，就是七层 nn.Sequential，激活函数用 tanh（和原始论文一致）：

import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(1, 6, 5),              # C1: 1→6, 5×5
    nn.Tanh(),
    nn.AvgPool2d(2, stride=2),       # S2: 2×2 avg pool
    nn.Conv2d(6, 16, 5),             # C3: 6→16, 5×5
    nn.Tanh(),
    nn.AvgPool2d(2, stride=2),       # S4: 2×2 avg pool
    nn.Conv2d(16, 120, 5),           # C5: 16→120, 5×5
    nn.Tanh(),
    nn.Flatten(),
    nn.Linear(120, 84),              # F6: 120→84
    nn.Tanh(),
    nn.Linear(84, 10),               # 输出: 84→10
)

注意看，这段代码只定义了数据的流动路径。nn.Conv2d 和 nn.AvgPool2d 是结构层，它们不关心反向传播、不关心优化器——它们只管一件事：输入进来，输出出去。

3.3 池化层：没有可学参数的结构层

池化层在整个 CNN 结构里是最特殊的一层——它没有任何可学习的参数。它就是一个固定的下采样操作。

两种最常见的池化：

池化类型做法设计哲学
MaxPool取窗口里的最大值只要"有没有"这个特征，不管它在窗口里的精确位置
AvgPool取窗口里的平均值对特征的强度做平均估计

设计哲学：一张猫片里，只要知道"这里有一只猫耳朵"就够了，不需要知道"猫耳朵的精确像素坐标"。池化层丢弃精确位置信息，这就叫局部平移不变性。

一个 2×2 的 MaxPool 步长为 2，会把空间尺寸缩小一半。比如 224×224 → 112×112（如 Fig.4 左→中所示）。

4. 知识扩展

4.1 CNN 家族的演进史

LeNet 是 CNN 家族的第一个成功实例，但它只是一个起点。后面十几年里，CNN 的结构在不断演化，每一次演进都解决了上一代的一个关键瓶颈：

网络年份核心结构改进解决什么问题
LeNet-51989卷积 + 池化 + 全连接的基本骨架手写数字识别（第一个实践验证）
AlexNet2012更深（5 层卷积） + ReLU + Dropout更复杂的图像分类（ImageNet 大规模赢下）
VGG2014全用 3×3 小卷积核堆叠统一卷积核设计，方便堆叠和扩展
ResNet2015引入残差连接（skip connection）解决深度网络退化问题（152 层也能训）

LeNet-5 的具体结构已经在第 3 节写过了。后面三个网络会在各自的文章中单独展开，包括每层的详细配置和参数量。此外还有空洞卷积（Dilated Conv）、深度可分离卷积（Depthwise Separable Conv）等结构变种，也在后续文章中介绍。

4.2 感受野

感受野（Receptive Field）的定义很简单：输出特征图上的一个点，对应输入图像上的多大区域。

拿 Fig.2 来说：3×3 的卷积核，输出上的一个点对应输入上的 3×3 区域。所以 Conv1 的感受野是 3×3。

那经过两层卷积之后呢？第二层卷积的输出上的一个点，对应第一层特征图上的 3×3 区域，而这 3×3 区域里的每个点都对应原始输入的 3×3 区域。两层叠加，感受野变大了。

假设输入和输出通道数相同（都是 c），想让感受野达到 7×7。有两种方案：

方案结构参数量非线性次数
A1 层 7×7 卷积49c249c^249c21
B3 层 3×3 卷积27c227c^227c23

方案 A 直接用一个 7×7 的卷积核，参数量是 7×7×c×c=49c27 \times 7 \times c \times c = 49c^27×7×c×c=49c2。方案 B 用三层 3×3 堆叠，每层 3×3×c×c=9c23 \times 3 \times c \times c = 9c^23×3×c×c=9c2，三层共 27c227c^227c2——参数量只有方案 A 的一半多一点。

感受野呢？第一层 3×3，第二层在第一层的输出上再看 3×3，两层叠加后覆盖了原始输入的 5×5，第三层再叠加——刚好达到 7×7，和方案 A 一样。

方案 B 用了更少的参数，达到了同样的感受野，还多了 3 次非线性变换（表达能力更强）。这就是为什么 VGG 之后，CNN 几乎清一色地用 3×3 小卷积核堆叠，而不是大卷积核一步到位。

一句话记住：堆叠小卷积核 = 更大感受野 + 更少参数 + 更强非线性。

4.3 CNN 的设计先验

回头看 CNN 的两个结构创新，背后有两个底层假设在支撑。

局部性先验（Local Prior）：邻近像素之间关系紧密，远处的像素之间关系微弱。决定一张图"是什么"的信息，全集中在关键区域的局部范围内——猫耳朵的信息在耳朵附近，不在远处的空白墙。CNN 用局部连接把这个假设写死了。

平移不变性（Translation Invariance）：一个特征在左上角出现和在右下角出现，本质上是同一个特征。边缘检测器在左上角能检测到边缘，在右下角也能，不需要为每个位置学一套不同的权重。CNN 用权值共享把这个假设写死了。

这两个假设不是数学定理，而是人类对"图像数据应该长什么样"的理解。CNN 之所以比 MLP 更高效，不是因为它更聪明，而是因为它带着更准确的先验知识上场。
