实例分割算法：为每个目标生成独立 Mask

约 5415 字大约 18 分钟

跨时代算法实例分割图像分割

1. 实例分割任务是什么？

前面已经讲过两个相关任务：

  • 语义分割：判断每个像素是什么类别。
  • 目标检测：找出每个目标的类别和边界框。

实例分割把这两个要求放到了一起：

既要区分同一类别里的不同目标，又要找出每个目标包含哪些像素。

比如一张图里有两辆车，语义分割会把两辆车的像素都标成“车”；目标检测会分别给出两个边界框；实例分割则要生成两个独立的 Mask，分别表示车 1 和车 2 的准确轮廓。

1.1 从目标框到独立 Mask

三种任务的输出可以这样对照：

语义分割：每个像素一个类别，同类目标不分彼此
目标检测：每个目标一个矩形框，不描述框内的准确轮廓
实例分割：每个目标一个独立 Mask，直接描述目标包含哪些像素

矩形框里通常还会包含背景。实例 Mask 则由像素组成：属于当前目标的像素记为 1，不属于当前目标的像素记为 0。

车 1 Mask：只标出第一辆车的像素
车 2 Mask：只标出第二辆车的像素

因此，实例分割不只是“框得更紧”，而是把每个目标从背景和其他实例中逐像素分离出来。

1.2 一个实例分割结果包含什么？

一个实例分割结果通常包含三部分：

  • 类别（Class）：这个实例是什么。
  • 实例 Mask（Instance Mask）：这个实例包含哪些像素。
  • 置信度（Confidence Score）：模型对这个结果有多确定。

很多模型还会同时输出边界框，但边界框不是实例分割最终必须提供的结果。只要有实例 Mask，就可以找到 Mask 覆盖范围的最小外接矩形，反过来得到边界框。

所以实例分割算法可以定义成：

学习一个函数 f(x)f(x)f(x)，把一张图像 xxx 映射成一组实例，每个实例包含类别、独立 Mask 和置信度。

f(x)={(mi,ci,si)}i=1Nf(x)=\{(m_i,c_i,s_i)\}_{i=1}^{N} f(x)={(mi​,ci​,si​)}i=1N​

  • NNN：预测出的实例数量。
  • mim_imi​：第 iii 个实例的 Mask。
  • cic_ici​：第 iii 个实例的类别。
  • sis_isi​：第 iii 个实例的置信度。

图里有几个目标，最终就应该输出几个实例；如果图里没有目标，结果可以是空集合。任务目标也可以概括成一句话：类别要正确，Mask 要准确，同时尽量不漏掉、不误报、不重复输出实例。

1.3 实例分割的稳定算法骨架

不同实例分割模型的结构差别很大，但它们一直在完成同一套任务：

输入图像
→ 提取图像特征
→ 产生一组实例预测
→ 建立预测与真实实例的对应关系
→ 优化实例类别和 Mask
→ 输出最终实例集合

这里最关键的变化，是监督单位从“像素类别”变成了“独立实例”。语义分割只需要知道第 (i, j) 个像素是什么类别；实例分割还要知道它属于哪一个目标。

1.4 怎样训练、预测和评价？

一张训练图像通常带有两部分标注：

  • masks：形状为 (N, H, W)，记录 NNN 个真实实例各自的 Mask。
  • labels：形状为 (N,)，记录每个实例的真实类别。

如果模型依赖目标检测，还会使用 boxes 监督边界框。训练时，模型先产生一组实例预测，再确定每个预测应该学习哪一个真实实例。核心损失可以概括成：

L=Lcls+λmaskLmask+λboxLboxL=L_{cls}+\lambda_{mask}L_{mask}+\lambda_{box}L_{box} L=Lcls​+λmask​Lmask​+λbox​Lbox​

  • LclsL_{cls}Lcls​：分类损失，让实例类别正确。
  • LmaskL_{mask}Lmask​：Mask 损失，让预测区域接近真实区域。
  • LboxL_{box}Lbox​：边界框损失，只在模型预测边界框时使用。

Mask 损失常由像素级二元交叉熵、Focal Loss 或 Dice Loss 组成。计算完损失后，模型通过反向传播更新参数，再进入下一批、下一个 epoch。

预测时不再提供真实 Mask，模型只根据图像输出一组实例结果。传统模型还要筛掉低置信度和重复预测；一对一集合预测模型则可以直接输出实例集合。

评价时，需要先比较预测 Mask 和真实 Mask 的重叠程度：

Mask IoU=预测 Mask 与真实 Mask 的交集像素数预测 Mask 与真实 Mask 的并集像素数\text{Mask IoU}=\frac{\text{预测 Mask 与真实 Mask 的交集像素数}} {\text{预测 Mask 与真实 Mask 的并集像素数}} Mask IoU=预测 Mask 与真实 Mask 的并集像素数预测 Mask 与真实 Mask 的交集像素数​

在此基础上，再计算 Mask AP。它和目标检测中的 AP使用同一套置信度排序、匹配与面积计算逻辑，区别是：目标检测使用边界框 IoU 判断是否匹配，实例分割使用 Mask IoU。

2. 实例分割必须解决哪些设计问题？

实例分割的任务定义长期稳定，但“怎样得到每一个独立 Mask”没有唯一答案。不同模型的主要差别，可以还原成下面三个设计问题。

2.1 怎样区分同一类别的不同实例？

假设图里有两辆相互靠近的车。模型不仅要知道这些像素属于“车”，还要把它们拆成车 1 和车 2。常见方法可以分成三类：

  • 检测后分割（Detect-then-segment）：先用边界框区分目标，再在每个目标区域内生成 Mask。
  • 位置驱动（Location-based）：根据目标中心或空间位置，让不同位置分别负责不同实例。
  • 实例查询（Instance Query）：准备一组可学习的 Query，让每个 Query 尝试寻找并分割一个实例。
  • 提示驱动（Prompt-based）：由点、框、图像示例或文字指出要寻找的目标，再生成对应实例的 Mask。

它们都在解决同一个问题：图像最终要输出数量不固定的一组实例，模型必须给每个实例安排一个独立的预测位置。

2.2 每个实例的 Mask 怎样生成？

区分实例之后，还要决定怎样表示它的准确轮廓。

候选区域内逐像素预测：

目标边界框 → 取出区域特征 → 在区域内部预测二值 Mask

这类方法先缩小范围，再判断框内哪些像素属于当前实例。Mask R-CNN 就采用这种方式。

原型 Mask 与实例系数组合：

整张图生成一组原型 Mask
+ 每个实例预测一组组合系数
→ 组合成当前实例的 Mask

原型 Mask 可以重复使用，模型不必为每个实例单独运行一套完整的 Mask 网络，因此更适合实时预测。YOLACT 和部分实时实例分割模型采用这种思路。

Query 直接预测 Mask：

一个 Query → 一个类别 + 一个完整 Mask

每个 Query 读取图像特征，再直接产生自己的类别和 Mask。Mask2Former 属于这类集合式 mask prediction。

提示条件下生成 Mask：

图像特征 + 点 / 框 / 示例 / 文字提示 → 提示对应的一个或多个 Mask

提示告诉模型“现在要分什么”。SAM 1 和 SAM 2 主要根据视觉提示选择特定目标，SAM 3 还可以根据文字或图像示例找出同一概念的全部实例。

2.3 预测怎样匹配真实实例并避免重复？

一张图可能只有 5 个真实实例，模型却会产生几十甚至几百个候选预测。训练时必须确定每个预测应该学习哪一个真实实例。

传统的检测后分割和密集预测方法通常使用一对多匹配（One-to-many Matching）：一个真实实例可以让多个候选预测同时学习。这样能提供更多训练信号，但预测时也可能对同一个实例输出多个结果，因此通常需要非极大值抑制（Non-Maximum Suppression，NMS）去重。

Query-based 方法通常使用一对一匹配（One-to-one Matching）：一个真实实例只分配给一个 Query，其他 Query 学习“无目标”。匈牙利匹配会综合类别和 Mask 的匹配代价，为整组预测寻找总代价较小的一对一组合。

提示分割在预测时由提示限定目标范围，不一定需要先把所有候选预测分配给固定类别。自动生成大量 Mask 时，仍然需要根据 Mask 质量、稳定性和重叠程度筛掉低质量或重复结果。

所以实例分割也不只是“给目标检测增加一张 Mask”。当实例来源、Mask 表示和匹配方式发生变化时，整套实例生成方法也会随之变化。

3. 实例分割算法的演进

理解了上面三个设计问题，再看论文演进就会更清楚：每条路线都在重新回答“实例从哪里来、Mask 怎样生成、重复结果怎样处理”。

3.1 2017：检测后分割，Mask R-CNN 成为经典基线

Mask R-CNN 建立在 Faster R-CNN 之上。Faster R-CNN 原本已经能够产生候选区域，并预测每个区域的类别和边界框；Mask R-CNN 在旁边增加了一条 Mask 分支：

候选区域特征
├── 类别分支：这个目标是什么？
├── 边界框分支：目标框应该怎样修正？
└── Mask 分支：框内哪些像素属于这个目标？

三个分支共享图像特征，但分别完成分类、定位和像素分割。因为候选区域已经把不同目标分开，Mask 分支只需要在当前区域内区分“属于这个实例”和“不属于这个实例”。

Mask R-CNN 还使用了感兴趣区域对齐（Region of Interest Align，RoIAlign），减少候选区域在提取特征时产生的位置偏移。实例 Mask 对像素位置很敏感，这个改动对边界质量很重要。

这条路线可以概括成：

先检测实例 → 再为每个实例生成 Mask

它把目标检测和像素分割组合成了一套清晰、稳定的框架，后来也长期作为实例分割的重要基线。

3.2 2019-2020：直接生成 Mask，并走向实时

Mask R-CNN 需要为每个候选区域提取特征并运行 Mask 分支。目标数量增加时，这些逐实例计算也会增加。于是一些模型开始寻找更直接、更适合实时预测的办法。

YOLACT（You Only Look At CoefficienTs） 把 Mask 生成拆成两个并行任务：

  1. 整张图只生成一次原型 Mask。
  2. 每个实例预测一组组合系数。

最后用不同系数组合相同的原型，就能得到不同实例的 Mask。详细组合过程放在原型 Mask 与实例系数中。

按位置分割目标（Segmenting Objects by Locations，SOLO） 则进一步摆脱边界框。它把图像划分成网格，根据目标中心位置决定由哪个位置负责当前实例，再直接输出这个实例的类别和 Mask：

目标中心位置 → 确定负责位置 → 直接预测实例 Mask

两者的具体设计不同，但共同说明了一件事：实例分割不一定要先得到候选框，再逐个运行 Mask 分支。

  • YOLACT：用共享原型和实例系数减少重复计算。
  • SOLO：根据位置区分实例，直接生成 Mask。

这一阶段让单阶段、实时和无框实例分割成为了清晰的研究路线。

3.3 2021-2022：Query 直接预测一组 Mask

MaskFormer 提出 Mask 分类（Mask Classification）：模型不再把分割只理解成“每个像素独立分类”，而是预测一组 Mask，并给每个 Mask 分配一个类别。

一组 Query
→ 每个 Query 输出一个类别和一个 Mask
→ 匈牙利匹配真实区域

Mask2Former 继续强化这套结构，让同一个框架可以完成语义分割、实例分割和全景分割。做实例分割时，每个有效 Query 对应一个独立实例；没有找到目标的 Query 输出“无目标”。

这条路线和 DETR 目标检测非常接近：

  • DETR：一个 Object Query 输出一个类别和边界框。
  • Mask2Former：一个 Mask Query 输出一个类别和 Mask。

训练时使用一对一匹配，预测结果天然是一组实例，因此不需要先放置 Anchor，也不必依赖传统的一对多候选框流程。

3.4 2023-2025：从提示分割到开放词汇实例分割

Mask2Former 仍然在一组预先规定的类别里预测实例。2023 年，分割一切模型（Segment Anything Model，SAM） 改变了 Mask 的使用方式：模型不再只接受图像，还会接收点、边界框或已有 Mask 等视觉提示（Visual Prompt）。

图像 + 点 / 框 / Mask 提示 → SAM → 提示所指目标的 Mask

SAM 1 本身不负责回答目标是什么类别，也不一定一次找出某个类别的全部实例。它更像一个通用 Mask 生成器：用户或其他模型先指出“要分哪里”，SAM 再生成准确轮廓。它也可以在整张图上密集采样提示，自动产生大量不带类别的候选 Mask。

2024 年，分割一切模型 2（Segment Anything Model 2，SAM 2） 把这套能力从静态图像扩展到图像和视频。用户只需要在某一帧中用点、框或 Mask 选中目标，模型就能利用记忆模块把这个目标的 Mask 传播到后续帧：

一帧中的目标提示 → 生成 Mask → 记住目标 → 在视频中持续分割和跟踪

2025 年，分割一切模型 3（Segment Anything Model 3，SAM 3） 又补上了关键的一步：除了点和框，还可以用文字或图像示例描述一个概念（Concept），模型会找出、分割并跟踪符合这个概念的全部实例。

图像 / 视频 + “红色汽车”
→ 找出所有符合描述的汽车
→ 为每辆车生成独立 Mask
→ 在视频中保持实例身份

这叫做可提示概念分割（Promptable Concept Segmentation，PCS）。它和传统实例分割的区别在于类别从哪里来：

  • 传统实例分割：类别集合在训练前固定，例如 COCO 的 80 类。
  • SAM 3：概念由预测时的文字或图像示例给出，可以分割训练类别表之外的目标。

所以 SAM 不是简单替换了 Mask R-CNN 的一个分支。它把实例分割从“训练一个固定类别模型”，扩展成了“用提示调用一个分割基础模型”。这类模型已经广泛用于交互式分割、数据自动标注、开放词汇分割和视频目标跟踪。

3.5 现在：经典、实时、统一与基础模型并存

Query-based 方法出现后，检测后分割和实时单阶段方法并没有消失。实际研究和工程中，几条路线仍在同时使用：

  • Mask R-CNN 路线：结构清楚，检测与 Mask 分支容易理解和修改，仍是常见基线。
  • 实时实例分割路线：强调速度和部署，Ultralytics YOLO Segmentation 会直接输出每个实例的 Mask、类别、置信度和边界框。
  • Query-based 路线：强调端到端集合预测，以及语义、实例和全景分割的统一。
  • SAM 基础模型路线：强调零样本迁移、视觉或文字提示、自动标注，以及图像和视频中的通用 Mask 生成。

这里还要区分 YOLO26 和 SAM 3。Ultralytics 已经集成 SAM 3，也支持 YOLO26 实例分割，但它们仍是两个独立模型：

  • yolo26n-seg.pt：固定类别、速度快，适合实时部署。
  • sam3.pt：根据文字、示例、点或框分割，适合开放词汇和交互式任务。

工程中还可以让 YOLO 先检测目标，再把边界框交给 SAM 生成 Mask，常用于自动标注。这是一条组合流水线，不代表 YOLO26 的网络结构内部使用了 SAM 3。

这些路线不是互相替代，而是对类别范围、速度、交互方式、视频能力和部署成本做出的不同选择。

3.6 抽象总结：变的是怎样得到每个实例的 Mask

演进路线实例从哪里来Mask 怎样生成类别或提示来源代表模型
检测后分割候选区域区域内逐像素预测固定类别标签Mask R-CNN
单阶段直接生成密集位置或目标中心原型组合或位置对应的 Mask固定类别标签YOLACT、SOLO
Query 集合预测一组可学习 Query每个 Query 直接预测 Mask固定类别标签MaskFormer、Mask2Former

这些模型改变的是实例来源、Mask 表示、匹配方式，以及类别从哪里来。传统实例分割的算法抽象仍然是：

输入一张图像
→ 输出数量不固定的一组实例
→ 每个实例包含类别、独立 Mask 和置信度

SAM 路线在输入端增加了提示：

输入图像 / 视频 + 提示
→ 输出提示对应的一组独立 Mask

两条路线共同稳定的部分没有变：最终都要把不同实例分开，并为每个实例生成独立 Mask。

4. 总结和扩展

4.1 RoIAlign 为什么对 Mask 边界重要？

Faster R-CNN 中的候选区域坐标不一定正好落在特征图的整数格点上。早期的 RoI Pooling 会把这些小数坐标取整，再把候选区域切成固定大小的网格。

对于目标检测来说，一点取整误差可能还能接受；但实例分割要判断每个像素属于目标还是背景，特征和原图错开一点，Mask 边界也会跟着偏移。

感兴趣区域对齐（Region of Interest Align，RoIAlign） 不再直接取整坐标，而是使用双线性插值计算采样位置的特征值：

RoI Pooling：小数坐标 → 取整 → 提取特征
RoIAlign：    保留小数坐标 → 插值采样 → 提取特征

它没有改变实例分割的任务定义，只是让候选区域特征与原图位置对齐得更准确，从而改善 Mask 的空间边界。

4.2 原型 Mask 与实例系数怎样组合？

YOLACT 不会为每个实例单独生成一张完整 Mask，而是先为整张图生成 KKK 张原型 Mask：

P1,P2,…,PKP_1,P_2,\ldots,P_K P1​,P2​,…,PK​

每个实例再预测 KKK 个组合系数：

ci1,ci2,…,ciKc_{i1},c_{i2},\ldots,c_{iK} ci1​,ci2​,…,ciK​

第 iii 个实例的 Mask 由这些原型加权组合得到：

Mi=σ(∑k=1KcikPk)M_i=\sigma\left(\sum_{k=1}^{K}c_{ik}P_k\right) Mi​=σ(k=1∑K​cik​Pk​)

可以把原型理解成模型为当前图像准备的一组基础形状和空间成分。不同实例使用不同系数，同样一组原型就能组合出不同 Mask。

这样做的关键不是“原型长得像某一种固定物体”，而是把大量计算放到整张图共享的原型分支里，每个实例只需要额外预测一组较短的系数。

4.3 和语义分割、全景分割、提示分割的关系

  • 语义分割：每个像素有类别，但不区分同类实例。
  • 实例分割：区分每个可数目标，并为每个目标生成独立 Mask。
  • 全景分割：既处理道路、天空这类背景区域，也区分车、人这类独立实例。
  • 提示分割：根据点、框、示例或文字提示输出区域，类别和实例范围由提示方式决定。

SAM 1 和 SAM 2 主要根据点、框或 Mask 找到特定目标，不一定自动给出类别；SAM 3 可以根据文字或示例找出某个概念的全部实例，已经和开放词汇实例分割发生明显重合。但它们仍然不等于固定类别、固定输出流程的传统有监督实例分割。

4.4 工程生态：Detectron2、MMDetection 与 Ultralytics

实例分割已经形成了成熟的工程生态：

  • Detectron2 提供 Mask R-CNN 等经典实现，适合研究区域检测和实例分割框架。
  • MMDetection 集成 Mask R-CNN、YOLACT、SOLO、Mask2Former 等不同路线，适合通过配置比较模型。
  • Ultralytics 同时提供 YOLO 实例分割与 SAM 1/2/3 接口，也能组合检测器和 SAM 自动生成数据标注。

这些工具箱不是新的实例分割算法。它们把模型、数据集、训练配置和部署接口组织到统一工程框架中，让使用者不必从零实现完整流程。
