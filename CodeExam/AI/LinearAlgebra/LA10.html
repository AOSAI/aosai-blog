LA10.实现向量到直线的正交投影

约 635 字大约 2 分钟

AI题库线性代数

难度：简单

正交投影与 L2 范数

向量范数的定义：

  1. L2 范数（欧几里得范数，最常用），就是我们平时说的向量长度或大小。在二维空间中：

∣∣L2∣∣2=L12+L22+⋯+Ln2≈x2+y2||L2||^{2}=\sqrt{L_{1}^{2}+L_{2}^{2}+\cdots+L_{n}^{2}}\approx{}\sqrt{x^{2}+y^{2}} ∣∣L2∣∣2=L12​+L22​+⋯+Ln2​​≈x2+y2​

  1. L1 范数（曼哈顿范数），测量的是沿坐标轴的“走路距离”。比如向量 [3, -4]，L1 范数的结果就是 7：

∣∣L1∣∣2=∣L12∣+∣L22∣+⋯+∣Ln2∣||L1||^{2}=|L_{1}^{2}|+|L_{2}^{2}|+\cdots+|L_{n}^{2}| ∣∣L1∣∣2=∣L12​∣+∣L22​∣+⋯+∣Ln2​∣

  1. L∞L\inftyL∞ 范数（最大范数），取绝对值最大的分量作为“长度”。

∣∣L∞∣∣2=max(∣L12∣,∣L22∣,⋯ ,∣Ln2∣)||L\infty||^{2}=max(|L_{1}^{2}|,|L_{2}^{2}|,\cdots,|L_{n}^{2}|) ∣∣L∞∣∣2=max(∣L12​∣,∣L22​∣,⋯,∣Ln2​∣)

什么是正交投影？给定向量 𝑣 和一个非零向量 𝐿，我们想把 𝑣 “投影”到 𝐿 的方向上。换句话说，我们想找到一个向量 𝑝 在 𝐿 的方向上，且 𝑣 - 𝑝 与 𝐿 垂直。推导：

1. 假设投影向量可以写作：p=λL2. 条件：𝑣 - 𝑝 与 𝐿 垂直：(v−λL)⋅L=v⋅L−λL⋅L=03. 解条件方程：λ=v⋅LL⋅L=v⋅L∣∣L∣∣24. 投影向量最终公式：projL(v)=λL=v⋅L∣∣L∣∣2⋅L\begin{aligned} &\text{1. 假设投影向量可以写作：}p=\lambda{L} \\[1em] &\text{2. 条件：𝑣 - 𝑝 与 𝐿 垂直：}(v-\lambda{L})\cdot{L}=v\cdot{L}-\lambda{L}\cdot{L}=0 \\[0.5em] &\text{3. 解条件方程：}\lambda{=}\frac{v\cdot{L}}{L\cdot{L}}=\frac{v\cdot{L}}{||L||^{2}} \\[0.5em] &\text{4. 投影向量最终公式：}proj_{L}(v)=\lambda{L}=\frac{v\cdot{L}}{||L||^{2}}\cdot{L} \end{aligned} ​1. 假设投影向量可以写作：p=λL2. 条件：v - p 与 L 垂直：(v−λL)⋅L=v⋅L−λL⋅L=03. 解条件方程：λ=L⋅Lv⋅L​=∣∣L∣∣2v⋅L​4. 投影向量最终公式：projL​(v)=λL=∣∣L∣∣2v⋅L​⋅L​

解题思路 1：Python 数组手搓

Python 求平方根的方法有很多种：使用指数运算符 **0.5、使用 pow(x, 0.5) 函数、使用 math 数学标准库 math.sqrt(x)。保留三位小数，可以使用 round(x,3) 函数四舍五入，剩下的就是直接计算即可。

def orthogonal_projection(v, L):
    length = len(L)
    L2 = sum([item*item for item in L])**0.5
    v_new = [v[i]*L[i] for i in range(length)]
    result = [round((v_new[i]/L2)*L[i], 3) for i in range(length)]
    return result
